# Landscape-Estimation-
Use this tool to plan you renovations to your landscaping with interactive features.

## Shorts Studio
A dashboard for building vertical (1080x1920) shorts-style videos and exporting them as MP4.
Requires `ffmpeg`/`ffprobe` on PATH.

    python -m shorts_studio.server   # open http://127.0.0.1:8000

Upload clips, add them to the timeline, set start/length, reorder, add a caption, then click **Export MP4** and download.
